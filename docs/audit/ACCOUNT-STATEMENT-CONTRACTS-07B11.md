# عقود كشفَي الحساب وعارض القيود —7B11 جزئية

[التقرير](PHASE-07B11.md) و[التحقق](VALIDATION-07B11.md) يحددان السبب والدليل والقيود. **7B/7 غير مكتملتين،7B12 معلنة،7C لم تبدأ،8 غير مأذونة.** مصدر 10ba ودخول 1fbac9e منفصلان؛ لا معالجة أو تشغيل ERP أو SQL/WPF/Office/REPX/طباعة/تصدير فعلي. كل 25 خطة **not-executed**. قراءة 3 أجسام و XAML و DTO و 21 مساراً ليست كل feature/caller/child/template/schema/ACL/سياسة/نشر.

## 1. سلاسل المصدر والهوية والنتيجة

1. **المفصل:** Home يطبق Apply/Settings قبل Show، ثم حساب leaf من Index واختيار/كود، ثم سابق state1 وحركة detail أو aggregate افتراضي، ثم صفوف ورصيد وتجميع، ثم RestrictionData و Statement/Statement2 REPX. بوابة P3-022 للتجميع غير الفارغ تسبق العرض. حمل typefilter على الحركة دون السابق يحتاج سياسة opening معلنة؛ راديو الدائن/المدين يغير رؤية أعمدة لا عضوية الصفوف.
2. **الرئيسي:** Home ينشئ نافذة جديدة ويعرضها بلا Apply محلي في المقطع. قائمته ليست معطلة محلياً، بخلاف قائمتي المفصل والقيود المعطلتين؛ هذه شواهد مداخل متباينة لا حكم صلاحية نشر. ثم parentcode وbranch/year/dates إلىGetAccountStatement بنصين مرفقين لا إجراء نشر مصدق، ثمDataTable/DataView وتجميعperiod-only، ثمAccountStatementReportData/REPX أوClosedXML/XLSX حقيقي. علاقةid بـBranchId وعملة الحساب وحبيبةleaf تحتاج عقداً؛ لا نفترض تساوي أي رصيدين.
3. **القيود:** Home يحتفظ بمرجع static مع Apply/Settings؛ البحث والأنواع عبر ID، ثم تنقل id/date و GlobalID للتفاصيل، ثم GLData/REPX أو طفل. فتح فاتورة العارض برقم محلي دون branch يختلف عن EntryOper المقيد في المسار المراجع. مصدر Receipt غير منفذ، و Close مع المرجع الثابت امتدادان قديمان؛ لا غياب وحدة سندات أو تسرب ذاكرة مقاس.

كل ناتج يحتاج لقطة `rows + criteria + totals + DBidentity + foundation + health` من جيل واحد. قراءة اسم حساب أو تاريخ أو Foundation حية عند الطباعة قد لا تصف صفوفاً محملة سابقاً. الفشل ليس zero، و empty ليست نجاحاً مع totals قديمة. لا نفترض وجود worker أو طلبات async متنافسة حيث التنفيذ متزامن.

## 4. عقود المصالحة الستة: لا مساواة قسرية بين حبيبتين

### RC7B11-01 — الكشف الرئيسي والمفصل:أهلية القيد والحبيبة والفرع والإشارة

- **المصدر والهوية:** Entry.GlobalID→Entry_sub.EntryGlobalID والحسابات الفرعية تحت parent؛ id منتقي الفرع مقابل BranchId في join الاسم يحتاج mapping معتمداً.
- **الوحدة والإشارة والمقياس:** D-C داخلي موحد و previous+period=closing لحساب وعملة ثابتين؛ period-only لا يساوي closing تلقائياً، و double/N2 ليسا سياسة تقريب.
- **الفرع والفترة والأهلية:** state1 في المفصل ولا state في SP المرفق؛ شروط الحذف والفرع والنوع والوقت ومجموعة leaf تحتاج توحيداً قبل مقارنة المجاميع.
- **علاقة المستند و GL وحدودها:** مصدر GL مباشر لا صافي فواتير؛ لا إثبات تطابق إجراء نشر أو تسوية مستندات. معنى الحالة وتفرد أبعاد join يحتاجان عقداً.
- **مثال وشاهد مقابل:** معتمد 100 وملغى 40→140 مرفقاً مقابل 100 معتمداً فقط؛ سابق دائن 200 وحركة دائنة 50→250 لا 150. التجميع الافتراضي غير الفارغ خلف P3-022.
- **المخرج:** DataView→UI totals→AccountStatementReportData/RestrictionData→REPX؛ XLSX الرئيسي من Table والمفصل stub.

## 5. الأهلية و DB والمخرجات والثقة: ما لا يحسمه اسم الواجهة

- الوضع المعتمد يميز state1 من state2 والحذف و NULL/مجهول؛ إن اعتمد audit-all فله معنى ومقياس وحالة معلنة. مثال 100+40 ليس مرجعاً لنشر عميل. المدين/الدائن وإشارة السابق وتسمية period-only/closing تحتاج سياسة معتمدة.
- `Branches.id` و`BranchId` موجودان؛ يلزم mapping وتفرد وكاردينالية موثقة لكل join، لا إعلان عمود مفقود أو صف مضاعف فعلي من DDL وحده. `EntryTypes.Id` ليس index خيار دائم أو ترجمة لغة. قد يكون عدم حمل typefilter إلى السابق مقصوداً؛ يحسم بعقد.
- اختيار DB من Year_Previews لا يثبت اسم قاعدة مسموحاً أو توافق schema/حساب/فرع/مؤسسة. كل طلب و lookup وطفل و Foundation وقالب يجب أن يحمل مصدره الموثوق؛ إرجاع globalconnstr لا يثبت عزل جلسة صحيحاً.
- REPX calls فعلية، والقوالب الخارجية غير مفحوصة. manifest/DTO/إصدار/flags/نسخ/preview/طابعة/فشل والتفقيط والصفر والدقة والثقافة شروط قبول. File.Exists لا يثبت سلامة المحتوى، و preview لا يفترض طابعة إلا بعقد صريح.
- الرئيسي ينتج ClosedXML/XLSX typed ويحفظ ويغلق قبل Process.Start؛ لا CSV/HTML أو فشل finalize من قنوات أخرى. نصوص الخلايا حسب المكتبة والإصدار والمستهلك، دون Office أو تنفيذ صيغة الآن. helperExcel المفصل بلا write لا يجيز caller-success أو فتح ملف غير مكتمل.
- menu المعطل و Apply-before-Show شواهد صحيحة؛ لا تصديق لدور نشر أوتفويض trusted command/query من visual-tree فقط. الطفل والمصدر والطباعة والتصدير والتكلفة وسنة DB وفرعها تحتاج حراساً مستقلين؛ لا وراثة قبول من parent.
- N+1/Fill/UI-thread وترتيب date دون tie-breaker مؤشرات محدودة، لا index غائب أو benchmark/leak.7C لم تبدأ؛ مخطط وخطط منقحة وحجم وإذن قياس مستقل شروط الحكم.

### التصويب الإضافي B10

المثال الصحيح qty2×cost5=10 والمرجع 2×12×5=120، لا 20 مقابل 120. شاهد B10 المؤرشف كان 10 أصلاً. يبقى EX7B10-06/G138 كما سُلما، ويضاف التصويب في تقرير B11/G144/الشاهد الجديد فقط. هذا حد صريح للمدقق الهيكلي: لا يصادق كل النثر التاريخي أو سياسة تكلفة منشورة.
