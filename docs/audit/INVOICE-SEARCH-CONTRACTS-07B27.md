## 4. الشواهد السببية والضوابط

```text
155: SQL(serverProc2) -> snapshot{proc2} -> selectProc1 -> []
     same snapshot + All0 -> only proc2
     same2 -> proc2 [control]; fresh sourceProc1 -> proc1 [counterfactual control]
156: callerCond(status1) -> date or reset assigns Cond -> status0 may enter
     date still filters day; branch/deleted still guarded [controls]
     selection GID+branch consumer does not restore status1
157: purchase requestType1 -> source (20 OR1) -> GID retained
     local result lacks source type -> selected consumer maps sourceType20
     requested1/exact23/request20/not-done/branch mismatch/local7 [controls]
```

هذه أمثلة على سجلات وأعداد وأيام ترتيبية صريحة، لا SQL parser أو DataView أو DateTime أوتوقيت WPF. نوع 20 لا يكرر الصف بمنطق OR، و branch mismatch ضابط تطابق لا اختبار ACL. معنى InvoiceStatus التجاري والتفويض وأهلية وقت التنفيذ والحفظ عقود خارجية مطلوبة من H01/04.
