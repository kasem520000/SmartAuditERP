## 4. تفسير الحالات والحواجز

- **not-executed** لا يعني passed أو failed. عدم توفر Windows/SDK/schema/DTO/config/تعريف مقياس/تفويض أو تجاوز حاجز الخيط يجعل الخطة محجوبة لا ناجحة؛ لا تمنح أداة الوثائق إذناً لتشغيلها.
- **confirmed** عيب محلي بدليله وشروطه؛ لا صف منشور أو حادث أو ضرر GL أو وصول دور فعلي مفترض. **potential** معلق ولا يحسمه مثال يدوي أو syntax check. **repository-gap** حد هذه اللقطة لا نفي كل نشر خارجي.
- **المصدر/الواجهة/المخرج** تقارن بهوية وفترة ووحدة ومصدر صافي/نوع/حالة واحدة. ملف قالب موجود لا يحول SummaryD stub إلى تنفيذ، وCSV صحيح نحوياً لا يعني formula-safe، وfinalize لا يمنع خلط نتائج طلبين.
- **المقاييس الوثائقية** تحسب references/links متكررة لا عدد أخطاء أو ميزات/أسطر راجعها المدقق معنوياً. كل تاريخ بمدخلاته المجمدة الخاصة؛ بيانات source/checkout الأحدث لا تعاد كتابتها للتظاهر باستنساخ bytes أرشيف قديم.
- **الباقي7B9/7C** ظاهر لا إغلاق شكلي. UI-thread في السجل صحيح بالنسبة لقراءات controls والنشر المختارة؛ GlobalID/type في SummaryD موجودان؛ REPX في DecisionHelp محمل فعلاً؛ وSummaryD ينهي using قبل الفتح. شواهد مقابلة لا تغلق الأصول أو بقية القدرة تلقائياً.
