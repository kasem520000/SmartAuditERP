## 1. ثلاثة أشياء لا تخلط

1. **فحوص اتساق التدقيق الحالية:**Python stdlib/Git فقط؛ بصمات 827 أصلية و 199artifact محمية، انتقال السجل الدقيق 266→270، حفظ كل نواة/next_phase/G01–110، وربط IDs/نطاق/روابط وحساب اتحاد/مكمل وفرز المرشحين. النجاح توثيقي لا صحة ERP.
2. **20 نموذجاً يدوياً و 20 ملاحظة نصية في B6:**الأولى fixtures مستقلة مقصودة لا ترجمة C#/SQL ولا استدعاء دالة تطبيق، والثانية حدود نص/مقاطع لا call graph دلالياً أوتنفيذ مخطط. مثال 4 أو 80/50 لا يثبت أن ERP وصل إليه خلف حواجز البناء/البيانات/الكاتب/الإتاحة.
3. **31 خطة قبول/بوابة أدناه:**8 finding-specific،16 historical-root-regression،5 cross-cutting-contract،2 documentary-scope-or-authorization-gate. **كلها not-executed**؛ بوابتا اكتمال 7B7/7C ليستا مجتازتين بنجاح hash أو synthetic test جزئي. لا تشغيل ERP/SQL/WPF/Office/COM/مزود/جهاز أوإصلاح أوإذن 8.

## 4. حدود الشواهد الحالية

- العلم التاريخي وسعر 115/VAT15 مقابل إعداد حالي false، وعكسه، يعزلان ضريبة إضافية 0 وخصم 0. ليست P7-086 أو P4-003 أو سياسة ضريبية جديدة.
- الكمية 0.004×1000 تعطي gross0 مقابل raw4 لأن التقريب سبق المبلغ؛ Math.Round/N2 للعرض وحده ليس العيب. مثال التقسيم يستبعد midpoint case أو تكلفة مقام P7-077.
- type/head/line fixtures لجهات العمل يحسمها الكتالوج المرفق، ولا يفترض أن كاتب مرتجع مرتبط معيب اجتاز حواجزه. وحدة 1 تعزل وحدة القيمة، ومعامل 10 يعزل P7-041 بعملية شراء بسيطة.
- الحارس File.Exists قبل FlowDocument قراءة نصية، لا REPX أو renderer نُفذ؛ المنع الزائد لا يعالج بملف وهمي. Nkd PrintNo حلقة موجودة، و POS signed summary copy موجود.
- HTML text encoding مختلف عن CSV quote وعن formula؛ لا HTML/Office/JavaScript أوصيغ/URLs نُفذت. أي parser في نموذج ليس إثباتاً لسلوك مستهلك نشر، ولا file extension دليل قبول أو رفض كل برامج Excel.
- التاريخ النصف مفتوح يفترض midnight صريحاً في fixture؛ لا يفترض كل Time محتمل بـ DatePicker. حد to+24 مع<= مختلف عن الحالة التاريخية لاستبعاد آخر دقيقة لكنه امتداد أصل cutoff نفسه.
- source-only leads عن N+1/اتصال مملوك/Close/Task/Dispatcher ليست leak/index/latency.7C لم تبدأ؛ body/XAML كامل لا كل callers/templates أو ACL/نشر.
