- توحيد التصنيف (P6-001) يجعل قرار «قياسية/مبسطة» واحدًا في: حارس الحفظ (IsTaxCustomer)، محول UBL (Name)، فرع مسار API (isSimplified)، وشاشات المتابعة — فلا يذهب فاتورة لمسار تخليص وهي مبسطة أو العكس.
- سياسة الوضع اليدوي (P6-002): القياسية تُرسل تلقائيًا عند التفعيل (عقد التوأم)، والمبسطة عند الوضع التلقائي فقط — وشاشة المتابعة مسار الإرسال اليدوي للمبسطة.
- حدود معمارية موثقة (P6-003): نماذج ZatcaIntegrationSDK.dll وAuditorAPI.exe خارج المستودع — القيود المرصودة لا تُصلح دون تحريف ترجمة الأنواع الخارجية.
