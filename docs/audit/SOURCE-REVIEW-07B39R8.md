## 1. حجة LastProcess المشتركة

`frmRptItemsActivityDetailed.xaml.cs:209–232` واجهة `void` ذات أربعة أعداد فقط. تكتب الصنف والطرف والمخزن عند القيم الموجبة؛ `clientType==1` يختار العميل وما عداه المورد. لا طلب عرض إذا غاب الصنف والطرف الموجبان، حتى إن وصل مخزن موجب. كل المتصلين التسعة عشر يكتبون `Show` قبل النداء؛ **ليس ذلك إثباتًا لاكتمال Loaded تزامنيًا**.

`ShowResult:241–413` يثبت الحدود التالية:

1. **المخزن:** `chkAll` افتراضيًا true في XAML؛ `LastProcess` لا يجعله false. SQL لا يضيف شرط المخزن إلا عند `!all` وقيمة مختارة. دعم مباشر لـ**P7-122** القائمة.
2. **الطرف:** الكتابة إلى `SelectedValue` ليست ضمان ترشيح؛ يشترط الاستعلام `!allClients` و`SelectedIndex>-1` وقيمة غير null. فهرس/تحويل غير صالح أو نوع قائمة مختلف قد يفقد قيد الطرف، دون ادعاء أن كل معرف يخطئ؛ النوع3 متاح في القائمتين.
3. **«آخر» حركة:** وضع last يطلب `TOP(1)` مع `ORDER BY inv.date ASC` ويتجاوز شرط الفترة. دعم **P7-059**، لا نتيجة استعلام منفذ.
4. **الصحة:** القائمة تمسح قبل القراءة؛ `continue` عند غياب InvTypes/IsInput=0، وإضافة صفوف تدريجية ثم catch عام. Empty/Failed/Partial ليست نتائج معادة للأب، ولا يعني `ShowResult` أو non-null اكتمال الترطيب.
5. **الأصل والتفويض:** المنشئ يلتقط اتصالين جديدين من `MainClass.connstr` العامة، والفرع الافتراضي من الجلسة. لا يحمل النداء اتصال الأب/سنة صفه أو فرعه أو مجموعة المستندات المسموحة. الصلاحيات العامة تعطل أزرارًا وتعود عند غياب السجل؛ ليست شهادة ACL أو واقعة اطلاع غير مأذون.

## 4. الإدراج المرتبط: متى يُكتب الأب؟

المساعدان `InvoiceOper.InsertFromInv:3941–4026` و`InvoiceOperContract.InsertFromInv:2166–2243`:
