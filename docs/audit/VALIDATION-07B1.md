## 2. المتطلبات السابقة وضوابط الأمان المشتركة لكل خطة

- **المتطلبات:** إذن8 مستقل وبيئة Windows/WPF باعتماديات موثوقة مرخصة وSQL معزولة ذات DDL معلوم، أو doubles موثقة للمصادر وspool حسب السيناريو؛ حسم حواجز المصدر السابقة قبل اختبار الأثر اللاحق. لا بناء أو قبول تطبيق نفذ هنا.
- **الأمان:** هويات وأسماء وأرقام اصطناعية فقط؛ تعطيل sync والضريبة والدفع والبريد والرسائل وحجب الإنتاج؛ snapshots قبل وبعد وfaults محدودة ومراجعة bytes بأدوات محايدة. لا صيغ شبكة أو أوامر ولا أجهزة حية أو ثنائيات مجهولة.
- الحواجز التاريخية لـDDL/GlobalID والكتّاب والـDTO/SDK والقوالب قد تمنع بلوغ أثر لاحق. تسجل الخطة حينئذ **blocked مع سبب**، لا passed ولا فشل مالي مفترض؛ المعالجة نفسها تحتاج إذناً مستقلاً.
- استعمل adapters/doubles موثقة للـspool والمزود/التوقيت والفشل؛ لا fake مخترع لاستنتاج ضمان SDK مجهول. لا تشغيل bin/obj المتتبعة ولا callbacks خارجية. عزل خدمة mail/WhatsApp/pay/tax/sync شرط قبل أي اختبار مستقبلي.
- سجّل expected/actual وهوية المصدر/version/criteria/Actor/scope وbefore/after منقحة دون بيانات حساسة؛ نجاح UI أو ملف لا يكفي لإثبات commit/GL/تسليم مادي. نتيجة save وoutput وprovider منفصلة.
- مواصفات العملة والفئات والمرتجع والضريبة والتأجير ومصادر المصروف وstate/FX والإقفال يقرها مالك محاسبي قبل fixtures الطرفية، لا تستنبط من أرقام enum أو أسماء أعمدة.

## 4. لماذا لا تعد الأمثلة قبولاً؟

Python Decimal/string/list/csv/zipfile لا تستورد دوال C# أو سلوك VisualBasic.Conversions أو SQL collation أو DevExpress أو برنامج جداول. مثال اختلاف العملة مجرد مقارنة فروع رقمية محلية، وخرجا helper للأرباح افتراض موثق لا نجاح SQL. مثال125/25 لتبويب الفواتير لا يثبت مساواة كل إجمالي مواد معtot_net. مثال التأجير100+15 مفصول عن حواجز الحفظ والإضافات/التأمين. =1+1 نص حسابي بريء لم يقيّم؛ بقاء البادئة ليس استغلالاً أو إثبات تفسير Excel. لا تحمل أمثلة التدقيق أسماء/أرقام هواتف/عملاء أو payload حقيقياً.

## 5. شروط اعتماد النتائج مستقبلاً

لا تغلق أي من223 بأمثلة Python أو فحص bounds. يلزم إذن8 وبيئة واعتماديات موثوقة وfixtures مرجعية ومصفوفة نجاح/فشل/حجب، ثم لكل معالجة مرجع جديد وإعادة ربط الأدلة قبل استعمال الأسطر القديمة. الفترة/العملة/الفرع/الصلاحية/السطر/العكس/فشل جزئي والنقر المتكرر أساسية. **الحالة الراهنة: تدقيق7B1 ساكن فقط، لا اكتمال7B أو7، ولا إصلاح أو تشغيل أو إذن8.**
