من جذر المستودع، Python3 وGit محليان فقط:

```bash

python3 docs/audit/tools/check_inventory_witnesses.py
```

- لا تستخدم `collect_baseline.py --write` لإخفاء اختلاف أو تغيير أدلة تاريخية. verify لا ينفذ التطبيق أو schema.
- أداتا3/4 مجمدتان؛ أداة5 تقرأ المقاطع المسماة وتنفذ أمثلة تدقيق مستقلة فقط؛ لا import ERP أو driver أو assembly أو طلب إنترنت/وسيط أو فك تشفير فعلي.

- نجاح bounds/regex/hash لا يثبت صحة تفسير semantics/أعمال أو مخطط نشر، ولا يثبت read-every-line أو WPF rendering أو exactly-once. مخرج [checks-05.json](evidence/checks-05.json) لا يحاول hash نفسه؛ عد المراجع/الروابط **يشمل التكرار** وليس نسبة تغطية.

## 4. ضوابط تنفيذ القبول لاحقاً — لا إذن تنفيذه الآن

1. تفويض تشغيل/مرشح معالجة منفصل، Windows وبناء موثوق مع نسخة .NET/DevExpress/DTO/SDK/SQL معروفة؛ لا استخدام binaries المرفقة لإثبات أن المصدر بنى، ولا أسرار في المحادثة.
2. SQL وبروكر/API/SDK fakes **معزولة فقط** ببيانات اصطناعية ومفاتيح وهمية ونسخة schema موثقة وsnapshot/restore؛ حظر كل وجهة إنتاج/ZATCA/ETA/دفع/بريد/WhatsApp/دعم/نسخ خارجي/طابعة حقيقية. وسيط sandbox لاحق يحتاج إذناً محدداً لا ربط broker العمل.
3. إذا كان العقد مجهولاً مثل SDK cleanup/received أو DTO/enums/aliases، فالجزء **blocked** حتى توفر العقد؛ fake مخترع لا يثبت المكتبة الحقيقية. حالات التوليد20/10 تثبت من mapper المنشور لا تخمين enum.
4. لكل خطة environment/commit/fixture/operation/version/expected/actual وأدلة raw DB/queue/messages/results دون بيانات شخصية أو أسرار؛ UI وSync boolean أو task-finished لا تكفي.
5. fault hooks وbarriers قبل/بعد local commit، enqueue، claim، publish، remote commit، ACK، clear، checkpoint، وrestart في كل حد؛ فقد الرد بعد commit **Unknown** لا rollback. لا تقتل خدمة عمل/تقطع شبكة إنتاج.
6. تزامن عمليتين فعليتين في مجلد/قاعدة معزولين عند اختبار file races، ومؤقت/نقرة وسياق جلسة بجيل مثبت؛ لا يكفي استدعاء serial مرتين لإثبات سلامة التداخل.
7. fixtures بفروع1/10، tenant ذي بادئة مشابهة، قاعدتين فيهما نفس raw ItemId، هوية قديمة/جديدة، سيريال Id مختلف عن ItemId، وحدات1/7 ومخزنين، empty/partial/retained/delayed/duplicate/tombstone، وانحراف ساعة مضبوط؛ قارن قبل/بعد وكل الروابط لا مجموعاً عاماً فقط.
8. بوابة P1-017 يجب أن تثبت كما هي؛ اختبار خلفها محجوب ما دامت تمنع المسار. لا ترقيع صامت لتشغيل publisher ثم نسب النتيجة للإصدار الأصلي؛ أي مرشح مصرح يوثق الفرق وإعادة الاختبار.
9. حسم Q5/Q3/Q4 مع المنتج/محاسب/أمن لسلطة التعديل/GL/snapshot/revoke/retention. لا اختيار سياسة مالية/هجرة IDs أو repair أرصدة لجعل الاختبار يمر؛ repair/replay/توليد GL/إرسال ضريبي قرارات مستقلة بحدود ونسخ ورجوع.
10. نتائج التطبيق اللاحقة تسجل passed/failed/blocked بالأدلة؛ الآن **not-executed لجميع64**، لا نجاح من مثال Python أو parse XML أو قراءة source.
