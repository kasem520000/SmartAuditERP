## 2. المسارات والحواجز والشواهد المقابلة

1. **ميزان المراجعة:** Home ينشئ نسخة ويطبق Apply قبل Show. مصدر الحسابات static والعرض لكل نافذة. leaf الكاملة تحسب السابق عند تفعيله، لكن parent والفرعي-only يسقطانه من الختام: الأصل P3-019. جمع كل طبقات العرض والتقريب 1 للمؤشر تحت P3-020، لا نتائج جديدة متعددة. حد العمق سبب جديد مستقل.
2. **أرصدة الحسابات:** movement و type0 يشتركان في أهلية state1/deleted0 وشرطي فرع الرأس والسطر. توجد إضافة فعلية للحسابات ذات الافتتاحي وحده؛ لا يُنسب إليها إسقاط CostCenter. لكن type0 داخل الفترة لا يمثل كل السابق، وساعتا الحركة لا تستخدمان في افتتاحي shortdate/+24.
3. **مراكز التكلفة:** GetParent لا يثبت closure للشجرة، ومطابقة الافتتاحي CCcode فقط مع أول صف، و GROUP BY باسم الحساب، وغياب opening-only union؛ الأصلان P7-052/053. subtype2 يضيف قيد المركز في SQL كشاهد ضبط جزئي. التفصيل يجلب directchildren، والتجميع لا يستعمل ساعتَي الاختيار؛ لا حكم موحد على كل الأوضاع.
4. **الصندوق:** المنتقي مقيد بالفرع الحالي، وربط الحساب بالاسم والفرع ثم أول Code يمد P3-008 رغم وجود Acc_Code في DDL. previous يقف عند shortdate والحركة تبدأ dt1 فتوجد فجوة عند 10:00: الأصل P7-062. GlobalID يحفظ في ProcessNo، لا يُسمى رقم سند محلياً.
5. **الطفل:** الأبوان Trial/Balances يطبقان Apply ثم Show ويحددان الحساب فقط. للطفل فترة وفرع و aggregate defaults؛ P3-022 في projection السابقة لم تعالج. CostCenter يمرر EntryGlobalID إلى مقطع EntryOper يسترجع branch، لا يثبت هذا كل router أوكل child أووراثة معايير الأب.
6. **الإخراج:** ثلاثة آباء تحمل XtraReport.FromFile فعلياً؛ Trial يبني FlowDocument خلف بوابة REPX غير مستعملة. CSV الأرصدة والمركز تكمل WriteAllText قبل shell؛ using-var للصندوق يبقى حتىبعد success/launch، امتداد potentialP7-108 فقط. CSV/HTML/format/encoding/text-cell جذور منفصلة.
7. **الوصول والموارد:** قوائم الآباء الأربعة disabled صراحة؛ ثلاثة new والصندوق static. Apply-before-Show و Closing/using شواهد فعلية، لا تفويض نشر أو إتاحة مثبتة أو leak-free أو سرعة/فهارس مقاسة.7C لم تبدأ من مجرد ذكر مخاطر المصدر.
