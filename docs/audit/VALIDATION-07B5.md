## 4. شروط أي قبول لاحق — لم ينفذ ولم يؤذن

- إذن8 مستقل و Windows/WPF واعتماديات موثوقة بإصداراتها، ومخطط SQL اختباري معروف وخطة استعادة وبيانات اصطناعية. ليس DDL المرفق شهادة نشر، ولا ثنائيات مجهولة بديل build من المصدر.
- حسم InvoiceTxt/UtilitiesProj/DevExpress/REPX/aliases والمخطط أولاً؛ سجل blocked ولا تعد تعذر الوصول إلى الاستعلام أو renderer نجاحاً. افحص source/projection/count/identity/totals قبل الصفحة أو spool.
- مرجع مالي مستقل للمبلغ والخصم والضريبة والوحدة والعكس والتحصيل و PaymentStatus/InvoicePayments، وعقد إعادة تصنيف لا يعيد التحصيل؛ لا تستنتج GL غير متوازن من فرق saved header/reloaded object وحده.
- عقد حوار Selected/Cancelled وفحص وجود الطرف ونطاقه داخل الأمر. منع UPDATE عند الإلغاء مطلوب حتى لو منع FK خارجي هوية0؛ ولا نجاح بعد صفر affected rows أو فشل القيد أو نسخة قديمة أو فترة مقفلة.
- معنى VATFilter ومصدره المختار تاريخي/مشتق، و mixed/null/zero/exempt/discount بإصدار وسياسة معلنة؛ لا migration أو UPDATE واسع لعلاج التقرير.
- source snapshot واحدة كاملة؛ partial/error/dirty ليست empty ناجحة. المصدر والبطاقات والمخرج من المعايير والإصدار نفسيهما، ومجاميع signed لا unsigned SUM.
- لا تشغيل دفع أو ضريبة أو مزامنة أو إرسال أو Office/صيغة أو طابعة أثناء هذا التدقيق. لا إعادة حفظ أو قيد فرق لإجبار المخرجات على المطابقة. أحكام latency/index/leak تحتاج قياسات وخططاً وحجماً وإصداراً وإذناً في المتابعة، لا نص per-row query فقط.
- prerequisites و safety_controls محفوظة لكل خطة في CSV. خطتا38/39 بوابتا نطاق/إذن بشريتان **غير منفذتين**، وليستا تنفيذ7B6/7C أو قبول8 بنجاح IDs.
